# MSFT Acute Mental Health Care Plan

A React/Vite care plan page for an acute mental health ward 5x5 activity.

## Run locally

```bash
npm install
npm run dev
```

## GitHub Pages

The built site is included in the `docs` folder. In GitHub Pages settings, choose:

- Source: Deploy from a branch
- Branch: main
- Folder: `/docs`

## Google Sheet integration

Submissions are sent to the configured Google Apps Script Web App URL in `src/App.jsx`.
